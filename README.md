# Quicksave Reloaded

A Factorio mod that adds a quicksave key (F6 by default). It saves the game to
`_autosave-quick<nr>`, rotating between 1 and 3 like the built-in autosave.
The rotation count and an optional save name can be set in the mod settings.

This is a continuation of [Quicksave](https://mods.factorio.com/mod/Quicksave)
by dandi345, whose last release was 0.4.0 for Factorio 2.0. It is published as
`Quicksave-reloaded` and keeps the original mod working on newer Factorio
versions. It replaces the original: disable or remove `Quicksave` when you
enable it, and existing saves keep their quicksave counter. The unmodified
upstream release is tagged `upstream-0.4.0`.
